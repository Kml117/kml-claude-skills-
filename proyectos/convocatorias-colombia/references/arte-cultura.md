# Arte y Cultura — Idartes, MinCultura y Entidades Territoriales

## Entidades Emisoras Principales

### Idartes (Instituto Distrital de las Artes — Bogotá)
- Becas y estímulos para creación, circulación y formación artística en Bogotá
- Convocatorias anuales por áreas: artes plásticas, música, teatro, danza, literatura, audiovisual
- Portal: https://idartes.gov.co/es/convocatorias

### MinCultura — Programa Nacional de Concertación Cultural
- Apoya festivales, eventos y procesos culturales de organizaciones en todo el país
- Dirigido a ONG, fundaciones y organizaciones culturales con personería jurídica
- Portal: https://www.mincultura.gov.co/concertacion

### Gobernaciones y Alcaldías
- Fondos de cultura locales con convocatorias anuales o periódicas
- Montos menores pero con menos competencia que el nivel nacional

## Tipos de Apoyo

| Tipo | Descripción |
|---|---|
| Beca de creación | Financiación de un proyecto artístico propio |
| Beca de investigación artística | Para documentar o investigar manifestaciones culturales |
| Estímulo de circulación | Para llevar un proyecto ya creado a nuevos públicos o territorios |
| Residencia artística | Estadía en un espacio para crear durante un período |
| Concurso con premio | Reconocimiento + dotación económica por obra seleccionada |

## Documentos Clave para Convocatorias Culturales

| Documento | Descripción |
|---|---|
| Portafolio artístico | Muestra de obra anterior (fotos, videos, grabaciones, textos) |
| Proyecto artístico | Descripción, objetivos, proceso creativo, cronograma |
| Presupuesto detallado | Por rubros: honorarios, materiales, logística, difusión |
| Hoja de vida artística | Formación, exposiciones, publicaciones, premios |
| Carta de intención / motivación | Por qué este proyecto · por qué ahora · impacto cultural |
| Soportes legales | Cédula, RUT, certificado si es persona jurídica |

## Estructura de un Proyecto Artístico Ganador

1. **Nombre del proyecto:** Evocador y descriptivo
2. **Sinopsis / Descripción:** Qué es, qué propone, de qué trata
3. **Intención artística:** Por qué este proyecto existe · qué quieres comunicar
4. **Proceso creativo:** Cómo vas a desarrollarlo paso a paso
5. **Impacto y alcance:** A quiénes va dirigido y cuántas personas alcanzará
6. **Cronograma:** Fases del proceso con duración
7. **Presupuesto:** Justificado rubro por rubro
8. **Hoja de vida:** Tu trayectoria como evidencia de que puedes ejecutarlo

## Consejos Estratégicos
- El portafolio es tan importante como el proyecto — muestra que tienes obra previa
- Las convocatorias culturales valoran la originalidad y la coherencia estética
- Mostrar impacto comunitario aumenta el puntaje en muchas convocatorias territoriales
- Revisar si la convocatoria es para personas naturales, jurídicas, o ambas
- Muchas convocatorias de Idartes tienen área específica — aplicar solo al área donde tienes fortaleza
